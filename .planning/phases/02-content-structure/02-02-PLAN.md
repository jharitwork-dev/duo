1. Create `src/server/actions/phase.ts` with `'use server'` directive:
   - `createPhase({ groupId, name, description? })` -- requireRole(TEACHER/SUPERADMIN), validates with Zod, gets max orderIndex for group (filtering isArchived=false), inserts phase with orderIndex = max + 1. If this is the first phase in the group (orderIndex 0), set status to 'active'; otherwise set to 'locked'. Returns `{ success: true, phaseId }`.
   - `updatePhase({ phaseId, name?, description?, isFreeAccess?, deadline? })` -- requireRole(TEACHER/SUPERADMIN), validates, updates phase fields. Returns `{ success: true }`.
   - `reorderPhases({ groupId, orderedIds: string[] })` -- requireRole(TEACHER/SUPERADMIN), verifies all IDs belong to this group and are not archived, wraps in `db.transaction()`, updates orderIndex for each ID based on array position. Returns `{ success: true }`.
   - `archivePhase({ phaseId })` -- requireRole(TEACHER/SUPERADMIN), sets isArchived=true, updatedAt=now. Returns `{ success: true }`.
   - `restorePhase({ phaseId })` -- requireRole(TEACHER/SUPERADMIN), sets isArchived=false, updatedAt=now. Returns `{ success: true }`.

2. Create `src/server/actions/todo.ts` with `'use server'` directive:
   - `createTodo({ phaseId, title, submissionMode? })` -- requireRole(TEACHER/SUPERADMIN), validates with Zod, gets max orderIndex for phase (filtering isArchived=false), inserts todo with orderIndex = max + 1. Returns `{ success: true, todoId }`.
   - `updateTodo({ todoId, title?, description?, notes?, submissionMode?, deadline? })` -- requireRole(TEACHER/SUPERADMIN), validates, updates todo fields. Returns `{ success: true }`.
   - `reorderTodos({ phaseId, orderedIds: string[] })` -- requireRole(TEACHER/SUPERADMIN), verifies all IDs belong to this phase and are not archived, wraps in `db.transaction()`, updates orderIndex. Returns `{ success: true }`.
   - `archiveTodo({ todoId })` -- requireRole(TEACHER/SUPERADMIN), sets isArchived=true. Returns `{ success: true }`.
   - `restoreTodo({ todoId })` -- requireRole(TEACHER/SUPERADMIN), sets isArchived=false. Returns `{ success: true }`.

3. Create `src/server/queries/phase.ts`:
   - `getActivePhases(groupId)` -- returns phases where groupId matches AND isArchived=false, ordered by orderIndex ASC, with nested active todos (isArchived=false, ordered by orderIndex).
   - `getPhaseById(phaseId)` -- returns single phase with its active todos.
   - `getArchivedPhases(groupId)` -- returns archived phases for restore UI.

4. Create `src/server/queries/todo.ts`:
   - `getActiveTodos(phaseId)` -- returns todos where phaseId matches AND isArchived=false, ordered by orderIndex ASC.
   - `getTodoById(todoId)` -- returns single todo with attachments.
   - `getTodoDetail(todoId, userId)` -- returns todo with attachments, for the detail page. Verifies user has access through group membership chain.
