# Phase 2: Content Structure - Context

**Gathered:** 2026-09-18
**Status:** Ready for planning

<domain>
## Phase Boundary

Full teacher content creation workflow: classrooms with invite codes/links, student groups with flexible assignment, ordered phases with expandable inline editing, and to-do items with submission mode, deadlines, notes, and attachments. Student navigation from home → group → phases → to-do detail page.

</domain>

<decisions>
## Implementation Decisions

### Classroom Management
- **D-01:** Students join classrooms via invite code (6-char) OR shareable invite link (build.innovators.co.th/join/ABC123). Teacher can also add students manually.
- **D-02:** Invite codes can be regenerated by the teacher.
- **D-03:** Classroom page (teacher view) is a full dashboard with: groups overview (member count + progress), recent submissions needing review, and classroom settings (edit name, manage invite code, remove students).

### Group Creation
- **D-04:** Groups can be formed by teacher manual assignment OR student self-join.
- **D-05:** Teacher can set a max group size per classroom.
- **D-06:** Each group is independent — its own phases and to-dos.

### Phase & To-do UI (Teacher)
- **D-07:** Phases created via inline add — '+Add Phase' button at bottom of phase list. Type name, press enter.
- **D-08:** Phases reordered via drag & drop.
- **D-09:** Phase details edited by clicking to expand inline — shows editable fields (name, description, deadline, free-access toggle).
- **D-10:** To-dos created via inline add within a phase — '+Add To-do', type name, set submission mode.
- **D-11:** To-do expanded inline shows: notes/instructions (plain text textarea), submission mode toggle (group/individual), deadline picker, attachments upload section.
- **D-12:** Notes/instructions are plain text (no rich text editor). Sufficient for v1.
- **D-13:** Teacher's group page layout: vertical list of phases as expandable sections, to-dos listed inside each phase (collapsible outline style).
- **D-14:** Soft delete for phases and to-dos — items are archived/hidden, not permanently deleted. Can be restored.
- **D-15:** Attachments managed in expanded to-do inline (upload button in the to-do expansion, not a separate page).

### Phase Templates
- **D-16:** Empty group state shows a template picker offering starter templates.
- **D-17:** 4 built-in default templates:
  1. "Market Research" (phases: questionnaire → interviews → analysis)
  2. "Product Development" (phases: ideation → prototype → testing)
  3. "Pitch Preparation" (phases: story → deck → practice)
  4. "Business Model Canvas"
- **D-18:** Teachers can save their own phase structures as reusable templates.
- **D-19:** Template picker shows both built-in and teacher-created templates.

### Student Navigation
- **D-20:** Student home auto-redirects to their group's phase view if in only 1 classroom. Shows classroom cards if in multiple.
- **D-21:** Entering a classroom goes directly to the student's group page (phases/to-dos view) — no intermediate classroom overview for students.

### To-do Detail Page (Student View)
- **D-22:** Single column layout: teacher notes at top → downloadable attachments → submission form → past submissions at bottom.
- **D-23:** Student sees: teacher notes, downloadable files, submission form (file/link/text), and their past submissions with feedback/status.

### Teacher-Student Views
- **D-24:** Same to-do detail page for both roles. Teacher sees extra controls (edit buttons, all group submissions, review tools) on top of what students see.
- **D-25:** No separate "preview as student" — teacher view is close enough.

### Claude's Discretion
- Drag & drop library choice (dnd-kit, react-beautiful-dnd, etc.)
- Inline add animation/interaction details
- Template data structure and storage approach
- Attachment upload UX details within expanded to-do
- Student classroom card design
- Responsive behavior for drag & drop on mobile

</decisions>

## Specific Ideas

- **Template picker** for empty groups with 4 Innovator's defaults + teacher-created templates
- **Soft delete** pattern — archived flag on phases and to-dos, not hard delete
- **Vertical collapsible outline** for phase/to-do management — expandable sections, not kanban
- **Inline add + inline expand** pattern throughout — fast, minimal clicks
- **Student auto-redirect** — skip intermediate pages when in single classroom/group
