# Quick 261008-0y9 Plan 01: Teacher "กลุ่มที่ฉันดูแล" filter on home + classroom Summary

Teachers can toggle `?mine=1` ("กลุ่มที่ฉันดูแล") on `/teacher` and on the classroom overview/groups tabs. The filter uses a pure `restrictSnapshotToGroups` helper and a single-query `getMyGroupIds`, so the status cards, matrix and summary counts all cover the same groups. The pill now lives in one shared component that `/teacher/review` also uses.

## Behavior
- `/teacher?mine=1`: only classrooms with at least one of my groups appear, each showing only my groups. Summary chips use the filtered counts and the subtitle changes to "สถานะงานของกลุ่มที่คุณดูแล". If I have no groups, one hint card shows instead. Overview links carry `&mine=1`. The "ห้องเรียนทั้งหมด" and archived lists are not filtered.
- `/teacher/classroom/[id]?tab=overview&mine=1`: the status cards and matrix come from the restricted dashboard. When I have no groups, `MINE_FILTER_EMPTY_HINT` shows.
- `?tab=groups&mine=1`: heading becomes "กลุ่มที่ฉันดูแล (n)", the grid is filtered, and an empty hint shows when n = 0. The toggle sits next to CreateGroupForm.
- Without `mine`, behavior is unchanged. `/teacher/review` looks the same as before: same classes, and `self-start lg:self-auto` is passed through `className`.
