## Deviations from Plan

1. **[Rule 1 - Correctness] Close date input:** the plan called for a `datetime-local` input read as Bangkok time. The builder uses the existing `DeadlineInput` instead, which converts through `bangkokInputToUtc`, so it stays correct when the browser is in a different time zone.
2. **[Rule 1 - Bug avoidance] Builder keying:** the plan keyed the whole `FormBuilder` by `form.updatedAt`. Every question action touches `updatedAt`, so that would wipe other unsaved question drafts. The settings card and each `QuestionEditor` are keyed by their own content instead.
3. **Extra file:** `src/components/form/form-pills.tsx`, a shared server-safe status/meta pill.
4. Linked phases appear as the builder PageHeader subtitle ("อยู่ในงานของ Phase: …"), not as a separate list.
